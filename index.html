🔗 Compartilhar com outra pessoa

Publica os lançamentos e fechamentos de todos os meses no GitHub. Quem abrir o link do app (sem token nenhum) vê os mesmos dados automaticamente — só pra consulta, não lança nada.

Como criar (1x): no GitHub vá em Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Marque "Only select repositories" → escolha controle-de-aparas → em Permissions ative Contents: Read and write. Cole o token acima. Ele fica salvo só neste navegador. Remover token salvo.

Alternativa sem token: baixa o arquivo pra subir manualmente na raiz do repositório no GitHub.
